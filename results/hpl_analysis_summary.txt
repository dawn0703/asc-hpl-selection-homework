6. BCAST x DEPTH exploration
----------------------------
BCAST=1 DEPTH=0: 60.255 GFLOPS
BCAST=3 DEPTH=0: 55.743 GFLOPS
BCAST=1 DEPTH=1: 64.775 GFLOPS
BCAST=3 DEPTH=1: 67.005 GFLOPS

Best result within this mini-sweep:
BCAST=3 DEPTH=1: 67.005 GFLOPS

Relative to BCAST=1 DEPTH=0 in the same sweep:
+11.20%

DEPTH=1 outperformed DEPTH=0 at both BCAST settings.
The effect of BCAST changed with DEPTH, suggesting parameter interaction.

Because each cell was measured only once and the machine showed
substantial run-to-run variation, this result is treated as exploratory
rather than as a validated stable speedup.

8. Final interpretation
-----------------------
The main validated optimization result is the fixed-workload NB tuning:
NB=192 achieved a 5.10% higher mean GFLOPS than NB=128 under
N=18432 and P x Q=2x2.

The BCAST x DEPTH experiment provides additional algorithm-level
evidence but is reported as exploratory because it was not replicated.

Performance search is stopped here. Remaining work focuses on
analysis, reproducibility, repository organization, figures, and report.
